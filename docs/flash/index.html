huddleboard

Connect the Heltec WiFi LoRa 32 V4 over USB and flash it from this page (Chrome or Edge). After flashing, set up Wi-Fi when prompted.

Note: The release binary is built with secrets.example.h (example bridge URL and token). In v0.1 anyone using web flash must build their own binary with their own secrets; runtime configuration is planned for v0.2. The image at firmware/huddleboard-heltec-v4.bin is added by the release workflow; when serving this folder locally, copy it there or the flasher returns 404.
